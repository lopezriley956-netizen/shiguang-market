# 拾光集市 · 零基础 Git 安装与协作教学 — 设计说明

## 全局视觉约定

### ① 画布与安全区
- 画布 1280×720；padding 上下左右各 60px；内容区 1160×600（y 60–660）
- 页眉 y 60–110；标题 y 110–170；正文 y 180–640；页脚 y 670
- 封面 / 章节 / 高潮 / 结尾页可全出血，内容页严守安全区

### ② 配色方案（科技未来 / 科技深空）
- 主色 accent：`#63A7D4`（冷蓝）
- 底色 deep_bg：`#0B1521`；深色面板 `#232C37`
- 文字：一级 `#FFFFFF`、二级 `#A9CFE7`、正文 `#E7E8E9`、辅助 `#C9CCCE`
- 深底文字 on_deep：`#FFFFFF`
- 点缀色：`#4DA3FF`（冷蓝紫）；成功绿 `#5DCAA5`；警示红 `#F09595`
- 图表/步骤系列色：`#24428F` `#3A5CBC` `#63A7D4` `#8FBCE4` `#E3F1F8` `#13263B`
- 主色深档 accent_t：`#0F1920`；浅档 accent_l：`#B9D7EC`

### ③ 字体系统
- 中文标题：思源黑体 Bold（Source Han Sans）；正文：思源黑体
- 西文 / 命令：Barlow Condensed（仅标题大数字）；命令行用等宽呈现
- 字号阶梯：封面主标 76 / 章节大字 64 / 巨型锚点 96 / 页面主标 34 / 卡片小标 24 / 正文 20 / 注释 15

### ④ 视觉母题
- 每页标题下方一条 1px 冷蓝贯通细线（仅主标题一处），页脚左下固定「拾光集市 · Git 教学」小字 + 页码
- 编号统一用 accent 冷蓝的方角数字块

### ⑤ 配图清单
- 全篇不依赖位图：以命令CodeBlock、SVG流程示意、FAIcon 图标、色块构成
- 视觉类型统一为「扁平结构化图形 + 代码窗口」，全篇一致
